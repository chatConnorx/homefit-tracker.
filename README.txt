HOMEFIT TRACKER — installable app package

WHAT IT DOES
- Monday–Sunday home workout plan using bodyweight and 5 kg dumbbells.
- Tick off exercises, add notes and energy check-ins, mark days complete.
- Progress summaries, recent history, backup export and restore.
- Saves progress locally in the browser on this device.
- Offline app shell after first successful load, when hosted over HTTPS.

MAKE IT INSTALLABLE ON YOUR SAMSUNG
This package is ready to host, but it is not published to a public website yet.
For installation, it must be served from an HTTPS website (not opened directly as a file).

EASIEST ROUTE WITH GITHUB PAGES
1. On a computer or phone browser, sign in to GitHub or create an account.
2. Create a new public repository named homefit-tracker.
3. Extract this ZIP. Open the ck_fitness_tracker folder and upload its contents
   (index.html, manifest.json, sw.js, README.txt, and the icons folder) to the repository root.
4. In the repository, open Settings → Pages. Under Build and deployment, choose
   Deploy from a branch, select the main branch and /(root), then Save.
5. Wait for GitHub Pages to show the published website address.
6. On your Samsung, open that HTTPS address in Chrome. Open ⋮ and choose
   Add to Home screen or Install app. The exact wording can vary.

DATA AND PRIVACY
Workout data stays in this browser's local storage and is not uploaded. Export a backup
before clearing browser data or switching devices. Importing a backup replaces current data.

SAFETY
This is a general workout template, not medical advice. Use controlled technique and stop
if you feel pain, dizziness or unwell. Rest days are part of progress.
